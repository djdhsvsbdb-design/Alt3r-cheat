# Alt3r-cheat

Private CS2 server-side project scaffold.

## Scope

This repository can host a CounterStrikeSharp plugin for server-side configuration, a neutral menu interface, and non-targeting gameplay options.

## Safe development boundaries

- No player-targeting automation (aimbot/aim assist).
- No wall visibility or ESP features.
- No recoil manipulation or anti-cheat bypass.

## Planned structure

- `src/` — plugin source
- `config/` — sample server/plugin configuration
- `docs/` — setup notes

## Status

Initial documentation scaffold. Implementation is not yet added.
